# Decision gates

Checkpoints so the project doesn't get too big. If the answer is no, I switch to the fallback.

| When | Question | Answer | Fallback if no |
| --- | --- | --- | --- |
| End of week 1 | Can the iPhone record continuously while the app controls AirPods music? | | In-app replay and logging only, no video export |
| End of week 2 | Does HUSKYLENS track at rink distance? | | Use iPhone Vision, keep HUSKYLENS as the bench demo |
| End of week 2 | Do UWB cost and testing fit the budget and time? | | No UWB, list it as future work |
| End of week 4 | Is panning stable with the real phone on the stand? | | Fixed wide shot, still finish the wristband and app |
| End of week 6 | Does the whole app work end to end? | | Stop adding features, only test and fix |
